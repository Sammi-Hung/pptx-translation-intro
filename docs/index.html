公司內部簡報處理工具

PowerPoint 翻譯與備註語音嵌入

上傳 `.pptx` 後，系統會翻譯投影片文字與講者備註，並將備註轉成旁白嵌入原簡報，降低跨語言教材製作時間。

文

投影片文字翻譯

處理文字方塊與指定 Placeholder，盡量保留段落、字型、條列與版面。

聲

備註轉語音

每頁講者備註會翻譯成目標語言，並由 Windows SAPI 產生對應語音。

檔

輸出可下載簡報

語音會嵌入 PowerPoint 檔案，完成後可在保存期限內重複下載。

功能介紹1 / 8

第一眼看到的操作入口

首頁把任務拆成三件事：上傳簡報、選擇語言與模型、確認語音包狀態。使用者不需要理解後端流程，也能知道現在是否可以開始。

  • 只接受 `.pptx`，最大 50 MB。
  • 拖曳或點擊上傳都支援。
  • 語音包、語言與模型條件符合後才允許送出。

首頁畫面：左側上傳，右側集中語言、模型與語音狀態。

操作入口2 / 8

支援三種語言方向

目前支援繁體中文、英文與泰文。原始語言與目標語言不可相同，語音語言會跟著目標語言檢查。

語言規則

  • 繁體中文：`zh-TW`
  • 英文：`en-US`
  • 泰文：`th-TH`

送出條件

  • 檔案格式正確
  • 大小符合限制
  • 語言不相同
  • 語音包可用
語言設定3 / 8

可切換雲端與地端翻譯模型

翻譯服務被設計成獨立模組，可以依使用情境切換雲端模型或內部地端模型，不把 API 細節寫死在 PowerPoint 處理流程裡。

  • 雲端模型：適合網路穩定、需要較高翻譯品質時。
  • 地端模型：適合資料不出內網或測試內部模型能力時。
  • Mock 模式：沒有 API key 時仍可測完整流程。

模型選單可在送出前切換，處理中會鎖定避免狀態不一致。

模型切換4 / 8

處理流程與實際進度

1. 驗證

確認檔案格式、大小、語言與工作狀態。

2. 擷取

讀取投影片文字方塊、Placeholder 與講者備註。

3. 翻譯

逐頁翻譯投影片文字與備註，保留版面格式。

4. 語音

每頁有效備註產生一個獨立旁白音檔。

5. 輸出

將音訊嵌入投影片並驗證輸出簡報。

不是假動畫

前端每秒查詢後端工作狀態，進度條、頁數、階段與訊息都來自實際處理流程。

可中途停止

處理中可以按下「停止翻譯」。後端會在安全檢查點停止，不提供不完整下載。

完成後提供結果統計與下載

成功後會顯示輸出檔名、總頁數、已處理文字頁數、語音頁數、警告數量與到期時間。

  • 下載由瀏覽器決定儲存位置。
  • 檔案完成或停止後保留 30 分鐘。
  • 若驗證失敗，不提供不完整簡報。

完成畫面會提示警告，例如本機 SAPI 語音品質取決於安裝的語音包。

使用前請確認的條件

P

PowerPoint

正式音訊嵌入需要 Windows 電腦已安裝 Microsoft PowerPoint 桌面版。

語

Windows 語音包

目標語言需安裝對應 SAPI 語音包，否則無法產生該語言旁白。

鑰

模型設定

正式翻譯需設定 Gemini 或 Ollama；沒有設定時可用 mock 模式先測流程。

適合用途

跨語言教育訓練、內部簡報初稿、本機旁白測試、需要保留簡報格式的翻譯流程。

仍需人工確認

複雜版面、特殊字型、圖片內文字、表格與圖表文字不在第一版翻譯範圍內。
